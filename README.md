# levelxinc.com

The Level X website. Static pages plus a Jekyll blog, served by GitHub Pages.

## Layout

- `index.html`, `apps.html`, `privacy.html` — hand-built static pages. Jekyll copies
  them through untouched (no front matter = no processing). Rebuild `index.html`
  from `site-src.html` with `build.py` in the working project, not here.
- `_posts/` — blog posts (Markdown + front matter).
- `_layouts/`, `_includes/`, `assets/css/style.css` — the blog's template and styles.
  Design tokens mirror the static site: Archivo / Public Sans / IBM Plex Mono, dark.
- `blog/index.html` — the blog index.
- `robots.txt`, `llms.txt`, `og-image.png`, `favicon.svg`, `CNAME` — site-level files.
- `sitemap.xml` and `feed.xml` are generated by plugins; do not commit them.

## Writing a post

Add `_posts/YYYY-MM-DD-slug.md`:

```yaml
---
layout: post
title: "Title in sentence case"
date: 2026-10-01 09:00:00 +0000
tags: [topic, topic]
description: "One or two sentences. Used for the blog index, the meta description, OG tags and JSON-LD."
---
```

House rule for this blog: every statistic links to its original source, and posts
say when a figure is vendor-funded, dated, or from a single survey. Widely repeated
numbers that cannot be traced to a real study do not get published.

Optional: add a `faq:` list of `q`/`a` pairs to any page's front matter to emit
FAQPage structured data.
